# Documentos de referencia

Material de entrada proporcionado para definir y verificar los flujos operativos de la aplicación.
No forma parte del bundle, no se publica como activo web y no sustituye los documentos generados por
la aplicación.

| Carpeta            | Contenido                                           |
| ------------------ | --------------------------------------------------- |
| `cartas-de-porte/` | Modelo de carta de porte.                           |
| `facturas/`        | Factura de ejemplo para validación de presentación. |
| `furgoneta/`       | Manifiesto de ejemplo de la furgoneta.              |
| `rutas/`           | Hojas de ruta de ejemplo.                           |

Los documentos pueden contener información de carácter personal o comercial. No los uses como
activos públicos, no los subas a almacenamiento de producción y elimina o anonimiza los datos antes
de compartirlos fuera del equipo autorizado.
